Commandes Git indispensables

1. Configuration de base

  • git config --global user.name "votre nom"

    Nécessaire pour définir le pseudo

  • git config --global user.email "votre email"

    Nécessaire pour définir l'adresse mail

  • git config --global core.editor "votre éditeur de texte"

    Nécessaire pour définir l'éditeur de texte par défaut

2. Commandes indispensables

2.1 Git init

FR : Transforme un dossier ordinaire (locaux) en dépôt Git en créant le dossier caché .git. Nécessaire au début d'un projet créé en local : sans elle, Git ne suit aucun fichier. Exemple : git init

MG : Ilaina raha mbola en local ilay dossier ka hovaina ho lasa dépot git.

2.2 Git clone

FR : Télécharge un dépôt distant (GitHub) avec tout son historique et configure automatiquement origin. Nécessaire quand le projet existe déjà en ligne et que tu veux le récupérer sur ta machine, à la place de init + remote add. Exemple : git clone https://github.com/user/projet.git

MG : Ampiasaina rehefa hampiasa ny dépot efa misy any amin'ny Github. Ohatra: git clone https://github.com/user/projet.git

2.3 Git add

FR : Place les fichiers modifiés ou nouveaux dans la « zone de préparation » (staging area). Nécessaire avant un commit : Git ne commite que ce qui a été ajouté, ce qui permet de choisir précisément ce qui sera enregistré. Exemples : git add index.html (un fichier), git add . (tout)

MG : Ilaina rehefa nanova zavatra amin'ny fichier ampiasainao ka ho ataonao any amin'ny Github avieo. Atao alohan'ny git commit. Ohatra: git add index.html (rakitra iray), git add . (rehetra)

2.4 Git commit -m "titre modification"

FR : Enregistre dans l'historique une « photo » des fichiers préparés, avec un message qui décrit le changement. Nécessaire pour sauvegarder une étape de ton travail et pouvoir y revenir plus tard. Le message doit être court et clair. Exemple : git commit -m "Ajout de la section git init"

MG : Mienregister ny fanovana nato tamina dépot iary ary arahina famaritana kely momba ilay fanovana. Ohatra: git commit -m "Fanampiana ny fizarana git init"

2.5 Git branch

FR : Liste, crée ou supprime des branches (des lignes de développement parallèles). Nécessaire pour tester une nouvelle fonctionnalité sans toucher à la version stable (main). Exemples : git branch (lister), git branch nouvelle-fonction (créer), git branch -d nouvelle-fonction (supprimer)

MG : maneho ny branche rehetra misy, na ampiasaina hicréer brach vaovao (Branche: karazana lieu de travail ao anaty na repository iray). Ohatra: git branch (mampiseho), git branch nouvelle-fonction (mamorona), git branch -d nouvelle-fonction (mamafa)

2.6 Git switch

FR : Change de branche : les fichiers du dossier prennent l'état de la branche choisie. Nécessaire pour passer de main à une branche de travail et inversement. Exemples : git switch nouvelle-fonction, git switch -c autre-branche (crée puis bascule)

MG : Manova ny branche: mametraka hoe ito ny branche hapiasaiko eto. Ilaina mba hifindra avy amin'ny main mankany amin'ny branche hafa. Ohatra: git switch nouvelle-fonction, git switch -c autre-branche (mamorona avy eo mifindra)

2.7 Git fetch

FR : Télécharge les nouveautés du dépôt distant sans les fusionner avec ton travail local. Nécessaire pour voir ce qui a changé sur GitHub avant de décider de l'intégrer, sans risque de conflit immédiat. Exemple : git fetch origin

MG : Maka ny zavatra vaovao avy amin'ny branche hafa fa mbola tsy mampiditra na manova ny code ao aminao. Ilaina mba hijerena izay niova tao amin'ny GitHub alohan'ny hanapahana hampiditra azy, tsy misy loza hisian'ny fifandirana (conflit) avy hatrany. Ohatra: git fetch origin

2.8 Git push

FR : Envoie tes commits locaux vers le dépôt distant (GitHub). Nécessaire pour sauvegarder ton travail en ligne et le partager avec d'autres. La première fois, -u mémorise la branche distante. Exemples : git push -u origin main (première fois), git push (ensuite)

MG : Mandefa ny commit local anaty machine mankany amin'ny dépot GitHub. Ilaina mba hitahiry an-tserasera ny asanao sy hizarana azy amin'ny hafa. Amin'ny voalohany, apetaka ny -u mba itenenana fa à distant ilay dépot. Ohatra: git push -u origin main (voalohany), git push (aorian'izay)

2.9 Git pull

FR : Récupère les nouveautés du dépôt distant et les fusionne dans ta branche (équivaut à fetch + merge). Nécessaire avant de commencer à travailler, ou quand un push est refusé parce que GitHub contient des commits que tu n'as pas. Exemple : git pull origin main

MG : Mitovy amin'ny fetch fa izy fotsiny tonga de mifusionner miaraka amin'ny code an'ilay zavatra vaovao niova ary mampitambatra azy amina brance ray (mitovy amin'ny fetch + merge). Ilaina alohan'ny fanombohana miasa, na rehefa lavina ny push satria misy commit ao amin'ny GitHub tsy ananao. Ohatra: git pull origin main

2.10 Git commit (variantes)

FR : Cette commande existe déjà au point 2.4. Voici ses variantes utiles : git commit sans -m ouvre un éditeur pour écrire un message détaillé, et git commit --amend corrige le dernier commit (message oublié ou fichier manquant). Nécessaire pour rectifier une erreur avant de faire le push.

MG : Efa voalaza tao amin'ny 2.4 ity baiko ity. Ireto ny karazany mahasoa: ny git commit tsy misy -m dia manokatra mpanova soratra hanoratana hafatra amin'ny antsipiriany, ary ny git commit --amend dia manitsy ny commit farany (hafatra adino na rakitra tsy ampy). Ilaina hanitsiana hadisoana alohan'ny hanaovana ny push.

2.11 Git merge

FR : Fusionne une branche dans la branche actuelle. Nécessaire pour intégrer dans main le travail terminé sur une autre branche. Si les deux branches ont modifié les mêmes lignes, Git signale un conflit à résoudre à la main. Exemple : git switch main puis git merge nouvelle-fonction

MG : Mifusionner branche iray amin'ny branche actuellenao. Ilaina mba hampidirana ao amin'ny main ny asa vita tany amin'ny branche hafa. Raha nanova ny andalana mitovy ny sampana roa, dia manambara fifandirana (conflit) i Git ary tsy maintsy ovaina amin'ny tanana. Ohatra: git switch main avy eo git merge nouvelle-fonction
